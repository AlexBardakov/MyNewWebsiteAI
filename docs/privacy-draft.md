## 2. Категории субъектов персональных данных

- **Покупатели** — физические лица, оформившие заказ на Сайте или предоставившие свои данные в форме оформления заказа;

## 3. Перечень обрабатываемых персональных данных

3.1. Оператор обрабатывает следующие персональные данные **Покупателей**, предоставляемые ими непосредственно при оформлении заказа:

- имя (в свободной форме, как введёт покупатель);
- номер контактного телефона;
- адрес доставки (улица, дом, корпус, подъезд, этаж, квартира/офис, домофон) — только при выборе способа получения «доставка»;
- сведения о составе заказа и комментарии к нему.

3.2. Оператор обрабатывает следующие персональные данные **отправителей** подарочного сертификата:

- имя (в свободной форме);
- номер контактного телефона;
- текст пожелания получателю (если содержит данные о третьих лицах — на ответственности отправителя).

3.3. Оператор обрабатывает следующие персональные данные **получателей** подарочного сертификата (передаются отправителем):

- имя получателя;
- контактные данные получателя (номер телефона или e-mail).

3.4. **Не обрабатываются**: специальные категории персональных данных (раса, национальность, политические взгляды, религиозные убеждения, состояние здоровья, интимная жизнь), биометрические персональные данные, данные несовершеннолетних.

3.5. **Технические данные**: Сайт **не использует** системы веб-аналитики (Яндекс.Метрика, Google Analytics и аналогичные). IP-адреса и идентификаторы устройств посетителей **не сохраняются** Оператором. Файлы cookies используются исключительно для технически необходимых функций Сайта (хранение состояния корзины в браузере посетителя, поддержание сессии в защищённой части Сайта); внешние трекеры (пиксели, рекламные cookies) не устанавливаются.

> **Сверено с кодом:** в проекте отсутствуют подключения GA/Метрики/VK Pixel/FB Pixel; корзина хранится в `localStorage`, не передаётся на сервер до момента оформления.

Оператор обрабатывает персональные данные в следующих целях:

- связь с покупателем для уточнения деталей заказа, согласования времени доставки, информирования о статусе заказа, направления покупателю защищённой ссылки на оплату;
- оформление, оплата и доставка электронных подарочных сертификатов;
- рассмотрение обращений и претензий пользователей.

## 6. Способы и сроки обработки

6.1. Обработка персональных данных осуществляется:

- с использованием средств автоматизации (сервер Сайта, база данных);
- без использования средств автоматизации (в части ведения бумажных документов, связанных с приёмом и выдачей заказов, при необходимости).

6.2. Перечень действий с персональными данными:

сбор, запись, систематизация, накопление, хранение, уточнение (обновление, изменение), извлечение, использование, передача (предоставление третьим лицам в случаях, предусмотренных разделом 8), блокирование, удаление, уничтожение.

6.3. Сроки обработки и хранения персональных данных:

- персональные данные **покупателей в составе заказов** — **3 года** с момента оформления заказа (этот срок обусловлен общим сроком исковой давности по ст. 196 ГК РФ и сроком хранения первичных учётных документов согласно ст. 29 ФЗ «О бухгалтерском учёте»);
- персональные данные, связанные с **электронными подарочными сертификатами**, — **до момента использования сертификата получателем** либо до истечения срока его действия; в случае утраты сертификатом актуальности данные удаляются в течение 30 дней;
- по истечении установленных сроков персональные данные подлежат уничтожению либо обезличиванию.

6.4. Досрочное прекращение обработки осуществляется по отзыву согласия субъектом персональных данных (см. раздел 9).

## 8. Передача персональных данных третьим лицам

8.1. Оператор **не передаёт** персональные данные третьим лицам в рекламных, маркетинговых или иных коммерческих целях.

8.2. В случаях, когда передача персональных данных необходима для исполнения договора, Оператор передаёт ограниченный объём персональных данных следующим категориям третьих лиц:

**8.2.1. Службы такси, привлекаемые в качестве курьеров для доставки заказа.**
Оператор пользуется услугами действующих на территории Российской Федерации сервисов такси:

- ООО «Яндекс.Такси» (сервис «Яндекс Go» / «Яндекс Доставка»);
- сервис «Такси Максим» (ООО «Максим»).

Конкретный сервис выбирается Оператором в зависимости от доступности и оперативности на момент исполнения заказа. Передаваемые данные ограничиваются объёмом, необходимым для исполнения доставки: имя покупателя, номер контактного телефона, адрес доставки. Иные данные (например, сведения о составе заказа) службам такси не передаются. Каждая из указанных служб такси является самостоятельным оператором персональных данных и обрабатывает полученные данные в соответствии со своей политикой конфиденциальности.

**8.2.2. Банк, обслуживающий расчётный счёт Оператора.**
Оплата заказа производится покупателем самостоятельно по защищённой ссылке, направляемой Оператором через мессенджер / SMS на указанный покупателем номер телефона. Платёжная операция совершается на стороне банковского приложения покупателя; Оператор не получает и не хранит реквизиты банковской карты покупателя. Банк, обслуживающий счёт Оператора, обрабатывает сведения о платеже в рамках банковского законодательства и в качестве самостоятельного оператора персональных данных.

8.3. Передача данных, указанных в п. 8.2.1, является **необходимой для исполнения договора доставки**: при выборе покупателем способа получения «доставка» исполнение заказа без передачи данных курьеру технически невозможно. Согласие на такую передачу считается предоставленным покупателем в момент оформления заказа с выбранным способом получения «доставка». Покупатель, не желающий передачи данных курьерским службам, может выбрать способ получения «самовывоз».

8.4. Иным третьим лицам персональные данные не передаются, за исключением случаев, прямо предусмотренных законодательством Российской Федерации (например, по запросу уполномоченных государственных органов).
