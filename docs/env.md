# Переменные окружения (.env на сервере)

Файл: `/root/fourkingssite/.env`. После правки: `npm run build && pm2 restart fourkingssite --update-env`
(переменные `NEXT_PUBLIC_*` вшиваются при сборке, остальные читаются при запуске).

## Обязательные

| Переменная | Что это |
|---|---|
| `DATABASE_URL` | `file:./dev.db` — SQLite, путь считается от `prisma/schema.prisma` |
| `JWT_SECRET` | Секрет подписи админ-сессии и ссылок из уведомлений, **не короче 32 символов**. Смена секрета разлогинит админку и сделает недействительными уже отправленные ссылки |
| `ADMIN_PASSWORD_HASH` | bcrypt-хеш пароля админки. Создать: `npx tsx scripts/hash-password.ts`. Каждый `$` в хеше экранировать как `\$` |
| `NEXT_PUBLIC_YANDEX_MAPS_API_KEY` | Ключ API Яндекс.Карт (карты зон доставки) |

## Уведомления во ВКонтакте

| Переменная | Что это |
|---|---|
| `VK_GROUP_TOKEN` | Ключ доступа сообщества магазина с правом «Сообщения сообщества» |
| `VK_PEER_IDS` | Кому слать, через запятую: номер беседы (например `2000000001`) и/или id людей |

Как получить:
1. Сообщество ВК магазина → **Управление → Сообщения**: включить «Сообщения сообщества».
2. **Управление → Сообщения → Настройки для бота**: включить «Возможности ботов» и
   «Разрешать добавлять сообщество в беседы».
3. **Управление → Работа с API → Ключи доступа → Создать ключ**, отметить «Разрешить
   приложению доступ к сообщениям сообщества». Ключ → в `VK_GROUP_TOKEN`.
4. Создать беседу с теми, кому нужны уведомления, и добавить в неё сообщество
   (в беседе: «Добавить участников» → вкладка сообществ, либо кнопка «Добавить в беседу»
   в настройках бота сообщества).
5. На сервере: `node scripts/vk-setup.mjs` — покажет беседы и их номера (`peer_id`).
   Номер беседы → в `VK_PEER_IDS`.
6. Проверка: `node scripts/vk-setup.mjs --test` — в беседу придёт пробное сообщение.

В сообщениях — только обезличенная сводка (номер, состав, сумма, способ получения) и ссылка
на заказ на нашем сайте, действующая 4 часа (`/o/<токен>`, см. `lib/notify/view-link.ts`).

## Необязательные

| Переменная | Что это |
|---|---|
| `NEXT_PUBLIC_SITE_URL` | Адрес сайта для ссылок в уведомлениях. По умолчанию `https://fourkings.ru` |
| `NEXT_PROJECT_ROOT` | Корень проекта для сборки, если Next.js путается в путях. Обычно не нужен |
| `VK_API_BASE` | Адрес API ВКонтакте — только для тестов. По умолчанию `https://api.vk.com/method` |

## Больше не используются (можно удалить из .env)

`TELEGRAM_BOT_TOKEN`, `TELEGRAM_ADMIN_CHAT_ID`, `TELEGRAM_PROXY` — уведомления в Telegram
убраны (24.11.2026: с сервера нет доступа к Telegram). Прокси gost для Telegram тоже больше не нужен.
`NEXT_PUBLIC_YANDEX_MAP_ID` — старый конструктор карт. `ADMIN_PASSWORD` — заменён на `ADMIN_PASSWORD_HASH`.
