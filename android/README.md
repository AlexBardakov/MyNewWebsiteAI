# Four Kings Админ — Android-приложение

Приложение владельца сыроварни. Две вкладки внизу:
- **Заказы** — уведомления о новых заказах и сертификатах, список (фильтр «Активные / Все»,
  на вкладке — число новых), карточка заказа (позвонить, адрес, состав) и смена статуса;
- **Остатки** — утреннее «что сегодня в наличии»: все товары по категориям, поиск, фильтры
  «Все / В наличии / Нет», кнопки «−/+» и ввод точного числа. Сохраняется само через 0,7 с
  после последнего нажатия (5 быстрых нажатий = 1 запрос); при сворачивании — сразу.
  0 = «нет в наличии» на сайте. Остаток — целое число в кг или шт, как в веб-админке.

Тёмная тема — по настройке телефона.
Работает с сайтом через API `https://fourkings.ru/api/app` — описание в `../docs/app-api.md`.

## Как приходят уведомления
Без Firebase и сторонних служб (как в приложении МерчКит.Карты): телефон сам спрашивает
сайт «что нового?» — раз в 15 минут в фоне (WorkManager; это минимальный шаг Android)
и каждый раз при открытии приложения. Уведомление может прийти с задержкой до 15 минут,
а при экономии батареи (Xiaomi, Huawei, Samsung) — дольше. Поэтому в приложении есть
кнопка «Разрешить работу в фоне». Мгновенно о заказах сообщает ВКонтакте.

## Установка на телефон
1. Скопировать на телефон `FourKingsAdmin-<версия>.apk` (или собрать, см. ниже).
2. Открыть файл на телефоне → разрешить установку из этого источника → «Установить».
3. Открыть «Four Kings Админ» → войти паролем от админки сайта.
4. Разрешить уведомления; нажать «Разрешить» на плашке про работу в фоне.
   На Xiaomi дополнительно: Настройки → Приложения → Four Kings Админ → Контроль
   активности → «Нет ограничений», и включить «Автозапуск».

Если телефон потерян: веб-админка → **Приложение: устройства** → «Отключить».

## Сборка
Нужны JDK 17+ и Android SDK (переменная `ANDROID_HOME`).
```
cd android
./gradlew assembleRelease     # боевая версия → app/build/outputs/apk/release/app-release.apk
./gradlew assembleDebug       # отладочная → ходит на http://10.0.2.2:3100 (локальный сайт из эмулятора)
./gradlew assembleQa          # как боевая (R8), но на локальный сайт — проверить ужатую сборку
```
Перед новой версией увеличить `versionCode` (и `versionName`) в `app/build.gradle.kts`.

## Ключ подписи — ВАЖНО
Релизная версия подписывается ключом `E:\Cheese-site-rework\android-signing\fourkings-admin.jks`;
путь и пароли — в `android/keystore.properties` (копия лежит рядом с ключом).
Оба файла **не в git**. Сделайте резервную копию папки `android-signing` (например, на флешку
или в зашифрованный архив). Без ключа обновление «поверх» не установится — придётся удалить
приложение с телефона и поставить заново (данные не пропадут: всё хранится на сайте, нужно
только снова войти).

## Устройство кода
- `data/Api.kt` — запросы к сайту; `data/Models.kt` — форматы; `data/Prefs.kt` — ключ устройства.
- `work/Polling.kt` — опрос сайта (`Poller`), фоновое задание раз в 15 минут.
- `notify/Notifier.kt` — уведомления в шторке; нажатие открывает заказ.
- `ui/*` — экраны (Jetpack Compose): вход, заказы, заказ, сертификат, остатки.
- `ui/StockState.kt` — данные «Остатков» и автосохранение (живёт весь процесс, переживает поворот экрана).
